# Gameplay

Two paddles are positioned on opposite sides of the screen.

A ball begins near the center.

The ball continuously moves.

The ball must bounce from:

- paddles
- top wall
- bottom wall

If the ball passes the left side:

Right player scores 1 point.

If the ball passes the right side:

Left player scores 1 point.

After scoring:

1. Reset ball to center.
2. Wait approximately 1 second.
3. Launch ball again.

First player to 5 points wins.

Display the winner and allow the game to restart.

---

# Controls

Left paddle:

W = move up
S = move down

Right paddle:

Up Arrow = move up
Down Arrow = move down

Restart:

Space

---

# Paddle Behaviour

Paddles:

- move vertically only
- cannot leave the screen
- use collision detection
- have constant movement speed

Recommended speed:

400–500 pixels/second.

Movement must use delta so behaviour is frame-rate independent.

---

# Ball Behaviour

The ball should:

- start from the center
- move diagonally
- bounce from walls
- bounce from paddles
- reset after a player scores

Recommended starting speed:

400 pixels/second.

Slightly increase ball speed after paddle collisions.

Cap the maximum speed so the game remains playable.

Avoid perfectly horizontal or vertical ball trajectories.
